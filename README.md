# ovid.sh

The website of [Ovid](https://github.com/ovid-sh/ovid), generated by gen, a
program written in Ovid. Every page is HTML for people and Markdown for
agents, indexed in `llms.txt` and `site.jsonl`.

## Build

```sh
./build.sh                       # out/ is the site
OVID_REPO=../ovid ./build.sh     # with a local clone of ovid
```

Needs Go and Linux x86-64. `build.sh` runs three steps; each prints JSON
lines, the last with `"ok"`, and the first to fail stops the build:

| step | what |
|---|---|
| `capture.sh` | builds the ovid named in `OVID_COMMIT` and records what it prints into `captured/`: `ovid help` topics and demo transcripts run in a scratch module |
| `ovid test`, `ovid build` | tests gen and builds it; the build receipt goes into every page's footer |
| `gen` | renders `content/` into `out/` |

No ovid output on the site is typed by hand. A page includes it with
`` ```lang include=captured/<file> ``, and a change to ovid shows up the
next time the site is built against it. To move the site to a newer ovid,
change `OVID_COMMIT`; if gen no longer builds, that is a finding for ovid
(see `docs/FRICTION.md`).

## Layout

```text
OVID_COMMIT         the ovid the site is built with
capture.sh          ovid's output, recorded into captured/
content/pages.txt   the pages, in nav order: "name label"
content/<name>.md   a page
gen/                main: pages, the HTML template, llms.txt, site.jsonl
md/                 the Markdown subset, to HTML; code highlighting
text/               bytes: escaping, JSON strings, slugs, FNV-1a hashes
static/style.css    the one stylesheet; the site has no scripts
```

## The Markdown gen reads

A subset, and anything outside it is an error with file, line, column,
and source, not a guess:

- `#`, `##`, `###` headings; the first `#` is the page's title, and the
  first paragraph after it is its description
- paragraphs, `- ` lists (an item goes on over lines indented two spaces),
  and `|` tables whose second row is `|---|`
- ```` ``` ```` fences with a language: `console` (a transcript: `$ `
  commands, `# ` comments, `exit N`, JSON records), `jsonl`, `json`, `ov`,
  or anything else, shown as text; `include=path` takes the body from a file
- inline `` `code` ``, `**bold**`, `[links](url)`, and `\|` for a `|` in a
  table cell

Not yet: quotes, numbered or nested lists, images, raw HTML, rules.
